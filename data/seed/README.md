# Seed data

Leave this folder empty in a **public** repository: the CSV files are Yahoo Finance data.
Import the four `*_5min.csv` files on the Predicted **Data** page instead.

If your repository is private and you prefer to seed from GitHub, put the files here
(names must contain the symbol, e.g. `JIOFIN_5min.csv`) and run the
**First-time setup** workflow with "Load data/seed/*.csv" ticked.
